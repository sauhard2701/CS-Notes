# 32.1 Print Binary Tree Top to Bottom

## Problem Description

Print each node of the binary tree from top to bottom, and print nodes on the same level from left to right.

For example, the level-order traversal result of the following binary tree is: 1,2,3,4,5,6,7

## Solution

Use a queue for level-order traversal.

There is no need to use two queues to separately store the current level and the next level. When traversal of a level begins, the number of nodes currently in the queue is exactly the number of nodes on that level. Processing exactly that many nodes ensures that this traversal only visits nodes from the current level.

```java
public ArrayList<Integer> PrintFromTopToBottom(TreeNode root) {
    Queue<TreeNode> queue = new LinkedList<>();
    ArrayList<Integer> ret = new ArrayList<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        int cnt = queue.size();
        while (cnt-- > 0) {
            TreeNode t = queue.poll();
            if (t == null)
                continue;
            ret.add(t.val);
            queue.add(t.left);
            queue.add(t.right);
        }
    }
    return ret;
}
```
