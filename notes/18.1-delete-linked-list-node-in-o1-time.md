# 18.1 Delete Linked List Node in O(1) Time

## Solution

① If the node is not the tail node, directly copy the value of the next node into this node, point this node to the node after the next node, and then delete the next node. The time complexity is O(1).

② Otherwise, first traverse the linked list to find the previous node, then point the previous node to null. The time complexity is O(N).

<div align="center"> <img src="https://cs-notes-1256109796.cos.ap-guangzhou.myqcloud.com/4bf8d0ba-36f0-459e-83a0-f15278a5a157.png" width="600"/> </div><br>

In summary, if N operations are performed, the approximate number of node operations is N-1+N=2N-1. Here, N-1 is the total number of operations for the N-1 non-tail nodes, each handled in O(1) time, and N is the number of operations for one tail node handled in O(N) time. Since (2N-1)/N \~ 2, the average time complexity of the algorithm is O(1).

```java
public ListNode deleteNode(ListNode head, ListNode tobeDelete) {
    if (head == null || tobeDelete == null)
        return null;
    if (tobeDelete.next != null) {
        // The node to delete is not the tail node
        ListNode next = tobeDelete.next;
        tobeDelete.val = next.val;
        tobeDelete.next = next.next;
    } else {
        if (head == tobeDelete)
             // Only one node
            head = null;
        else {
            ListNode cur = head;
            while (cur.next != tobeDelete)
                cur = cur.next;
            cur.next = null;
        }
    }
    return head;
}
```
