## Problem Description

We can use 2\*1 small rectangles, placed horizontally or vertically, to cover a larger rectangle. How many ways are there to cover a 2\*n rectangle with n non-overlapping 2\*1 rectangles?

To cover a 2\*n rectangle, first cover a 2\*1 rectangle and then cover a 2\*(n-1) rectangle; or first cover a 2\*2 rectangle and then cover a 2\*(n-2) rectangle. Covering the 2\*(n-1) and 2\*(n-2) rectangles can be treated as subproblems. The recurrence is:

```java
public int rectCover(int n) {
    if (n <= 2)
        return n;
    int pre2 = 1, pre1 = 2;
    int result = 0;
    for (int i = 3; i <= n; i++) {
        result = pre2 + pre1;
        pre2 = pre1;
        pre1 = result;
    }
    return result;
}
```
