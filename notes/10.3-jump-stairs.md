## Problem Description

A frog can jump either 1 step or 2 steps at a time. Find the total number of ways the frog can jump up an n-step staircase.

## Solution

When n = 1, there is only one way to jump:

When n = 2, there are two ways to jump:

<div align="center"> <img src="https://cs-notes-1256109796.cos.ap-guangzhou.myqcloud.com/1b80288d-1b35-4cd3-aa17-7e27ab9a2389.png" width="300px"> </div><br>

To jump up n steps, the frog can first jump 1 step and then jump the remaining n-1 steps, or first jump 2 steps and then jump the remaining n-2 steps. The ways to jump n-1 and n-2 steps can be treated as subproblems, giving the recurrence:

<div align="center"> <img src="https://cs-notes-1256109796.cos.ap-guangzhou.myqcloud.com/508c6e52-9f93-44ed-b6b9-e69050e14807.jpg" width="350px"> </div><br>

```java
public int JumpFloor(int n) {
    if (n <= 2)
        return n;
    int pre2 = 1, pre1 = 2;
    int result = 0;
    for (int i = 2; i < n; i++) {
        result = pre2 + pre1;
        pre2 = pre1;
        pre1 = result;
    }
    return result;
}
```
