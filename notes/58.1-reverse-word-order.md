# 58.1 Reverse Word Order

## Problem Description

## Problem Description

```html
Input:
"I am a student."

Output:
"student. a am I"
```

## Solution

First reverse each word, then reverse the entire string.

The problem should have an implicit condition: no extra space may be used. Although the Java version uses String as the input parameter and therefore requires creating a character array with O(N) space complexity, the correct parameter type should match the original book: a character array, using only the space of that array. Any solution that uses extra space, including a recursive solution, will be heavily penalized in interviews.

```java
public String ReverseSentence(String str) {
    int n = str.length();
    char[] chars = str.toCharArray();
    int i = 0, j = 0;
    while (j <= n) {
        if (j == n || chars[j] == ' ') {
            reverse(chars, i, j - 1);
            i = j + 1;
        }
        j++;
    }
    reverse(chars, 0, n - 1);
    return new String(chars);
}

private void reverse(char[] c, int i, int j) {
    while (i < j)
        swap(c, i++, j--);
}

private void swap(char[] c, int i, int j) {
    char t = c[i];
    c[i] = c[j];
    c[j] = t;
}
```
