# 41.1 Median in Data Stream

## Problem Description

How can the median of a data stream be obtained? If an odd number of values has been read from the stream, the median is the middle value after all values are sorted. If an even number of values has been read, the median is the average of the two middle values after sorting.

## Solution

```java
/* Max heap, stores the left half of the elements */
private PriorityQueue<Integer> left = new PriorityQueue<>((o1, o2) -> o2 - o1);
/* Min heap, stores the right half of the elements, and all right-half elements are greater than the left half */
private PriorityQueue<Integer> right = new PriorityQueue<>();
/* Number of elements read from the current data stream */
private int N = 0;

public void Insert(Integer val) {
    /* Insertion must keep the two heaps balanced */
    if (N % 2 == 0) {
        /* When N is even, insert into the right half.
         * Because all elements in the right half must be greater than those in the left half, but the newly inserted element is not necessarily greater than the left-half elements,
         * first insert the element into the left half, then use the max-heap property of the left half to take out the heap top, which is the maximum element, and insert it into the right half. */
        left.add(val);
        right.add(left.poll());
    } else {
        right.add(val);
        left.add(right.poll());
    }
    N++;
}

public Double GetMedian() {
    if (N % 2 == 0)
        return (left.peek() + right.peek()) / 2.0;
    else
        return (double) right.peek();
}
```
