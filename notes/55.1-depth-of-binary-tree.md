## Problem Description

A path in a tree is formed by the nodes passed from the root node to a leaf node, including the root and leaf nodes. The length of the longest path is the depth of the tree.

## Solution

```java
public int TreeDepth(TreeNode root) {
    return root == null ? 0 : 1 + Math.max(TreeDepth(root.left), TreeDepth(root.right));
}
```
