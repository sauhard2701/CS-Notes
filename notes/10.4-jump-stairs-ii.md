## Problem Description

A frog can jump 1 step at a time, 2 steps at a time... and it can also jump n steps at a time. Find the total number of ways the frog can jump up an n-step staircase.

## Solution

### Dynamic Programming

```java
public int jumpFloorII(int target) {
    int[] dp = new int[target];
    Arrays.fill(dp, 1);
    for (int i = 1; i < target; i++)
        for (int j = 0; j < i; j++)
            dp[i] += dp[j];
    return dp[target - 1];
}
```

### Mathematical Derivation

To jump up n-1 steps, the frog can jump 1 step from n-2 steps, or jump 2 steps from n-3 steps..., so

```
f(n-1) = f(n-2) + f(n-3) + ... + f(0)
```

Similarly, to jump up n steps, the frog can jump 1 step from n-1 steps, or jump 2 steps from n-2 steps..., so

```
f(n) = f(n-1) + f(n-2) + ... + f(0)
```

Combining the above gives

```
f(n) - f(n-1) = f(n-1)
```

That is

```
f(n) = 2*f(n-1)
```

So f(n) is a geometric sequence.

```source-java
public int JumpFloorII(int target) {
    return (int) Math.pow(2, target - 1);
}
```
