## Solution

A recursive solution repeatedly computes some subproblems. For example, computing f(4) requires f(3) and f(2), while computing f(3) requires f(2) and f(1), so f(2) is computed repeatedly.

<div align="center"> <img src="https://cs-notes-1256109796.cos.ap-guangzhou.myqcloud.com/c13e2a3d-b01c-4a08-a69b-db2c4e821e09.png" width="350px"/> </div><br>

Recursion divides a problem into multiple subproblems, and dynamic programming does the same, but dynamic programming caches subproblem results to avoid solving the same subproblem repeatedly.

```java
public int Fibonacci(int n) {
    if (n <= 1)
        return n;
    int[] fib = new int[n + 1];
    fib[1] = 1;
    for (int i = 2; i <= n; i++)
        fib[i] = fib[i - 1] + fib[i - 2];
    return fib[n];
}
```

Because the ith term only depends on the (i-1)th and (i-2)th terms, storing only the previous two values is enough to compute the ith term, reducing the space complexity from O(N) to O(1).

```java
public int Fibonacci(int n) {
    if (n <= 1)
        return n;
    int pre2 = 0, pre1 = 1;
    int fib = 0;
    for (int i = 2; i <= n; i++) {
        fib = pre2 + pre1;
        pre2 = pre1;
        pre1 = fib;
    }
    return fib;
}
```

Because n is less than 40, the first 40 terms can be precomputed, after which the nth term can be obtained in O(1) time.

```java
public class Solution {

    private int[] fib = new int[40];

    public Solution() {
        fib[1] = 1;
        for (int i = 2; i < fib.length; i++)
            fib[i] = fib[i - 1] + fib[i - 2];
    }

    public int Fibonacci(int n) {
        return fib[n];
    }
}
```
